# Public API v0 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans task-by-task.

**Goal:** Complete Linear U1–U8 with type-only API, reproducible typing evidence and eight stacked branches.
**Architecture:** One type source in .pyi files. No resolver, cache, binding or injection implementation. A Python diagnostic harness compares exact error lines/codes for mypy and Pyright.
**Tech Stack:** Python 3.15, uv, mypy, Pyright, pytest, Ruff, ty.
**Spec:** docs/api/source-spec.md (verbatim Linear project document).

## Global Constraints

- Preserve dependency-injector declarations and .ref syntax; all bindings supplied at declaration.
- No public Any, casts, ignored diagnostics or checker plugins in examples.
- Runtime begins at U9; PEP 827 is a separate U12 experiment.
- Each task branches from the previous task, with one committed deliverable.

## Review Focus

- ParamSpec rejects missing, mistyped and unknown bindings for both functions and class constructors (Task 2).
- Descriptor class access preserves declarations; instance/group access preserves bound result types (Tasks 3–4).
- Aggregate references remain selector callables and reject Singleton children (Task 5).
- Explicit function arguments, required business arguments and async returns keep their types (Task 6).
- Annotated metadata mismatch is documented as undetected; endpoint direct calls remain required (Task 7).
